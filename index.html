DATA ANALYTICS & BUSINESS INTELLIGENCE

E-commerce sales & customer analytics

An end-to-end analysis of ~100K marketplace orders: a PostgreSQL star schema, nine business-question SQL queries, statistical tests in Python and a three-page Power BI dashboard.

SQLPostgreSQLPythonSciPyPower BIDAX
Findings & methodology

The pipeline

Eight Kaggle CSVs (Olist, Brazil) load into typed PostgreSQL tables, are cleaned into a star schema, and pass a ten-check data-quality gate before any analysis runs. Queries use CTEs and window functions for month-over-month growth, cohort retention, RFM segmentation and a seller Pareto. Reconciliation tests assert every output adds up to the same totals.

What the data says

Key findings (97,905 orders, Jan 2017 – Aug 2018)
Avg review, late vs on time2.27★ vs 4.29★
1–2★ rate, late vs on time62.4% vs 9.2%
Customers who order again3.0%
GMV from the top 10% of sellers66.5%

The review gap is significant (Mann-Whitney U, p < 0.001), and a logistic regression (hold-out AUC 0.73) ranks delivery time as the strongest predictor of a negative review. This is observational data, so it shows a strong association rather than proof of cause.

DATA & AI ENGINEERING

RAG document Q&A

A local document question-answering pipeline that retrieves relevant text before generating an answer with a small language model.

PythonLangChainFAISSTransformers
Pipeline & evaluation

The pipeline

Text documents are chunked and embedded, stored in a FAISS index, then retrieved into a grounded prompt. A retrieval-only mode exposes context without calling the language model.

Evaluation scope

The README reports hit-rate@3 of 8/8 on eight labeled questions over three sample documents. This measures retrieval on a small example set; it does not establish generated-answer accuracy.
